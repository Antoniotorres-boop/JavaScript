# API de Produtos com Node.js e SQLite

Este é um projeto de estudo desenvolvido para demonstrar o funcionamento de um **CRUD** (Create, Read, Update, Delete) utilizando Node.js e o framework Express.

## Tecnologias Utilizadas
- **Node.js**: Ambiente de execução.
- **Express**: Framework web para roteamento.
- **SQLite**: Banco de dados relacional leve e local.
- **JavaScript (ES6+)**: Linguagem de programação.

## Arquitetura do Projeto
O projeto segue uma estrutura de organização:
- `controllers/`: Lógica de negócio.
- `database/`: Configuração e conexão com o banco de dados.
- `routes.js`: Definição dos endpoints da API.
